# F103 目标主频对测速的影响（2026-10-26）

目标固件用 `stm32f103_scope`（已拷贝到 `firmware/target/stm32f103_scope`），
分别构建 60 / 72 / 96 MHz 三个主频版本，比较 DAP 的读写吞吐。

## 构建

`build.ps1` 增加了 60 MHz 支持：60 MHz 不是 8 MHz 晶振的整数倍，改用
HSE/2 ×15（`PLLXTPRE=1, PLLMUL=×15`）。

```
pwsh -File build.ps1 -Board cb -CpuMhz 96   -> build-cb/fw.elf
pwsh -File build.ps1 -Board cb -CpuMhz 72   -> build-cb-72mhz/fw.elf
pwsh -File build.ps1 -Board cb -CpuMhz 60   -> build-cb-60mhz/fw.elf
```

回读确认：

| 版本 | RCC_CFGR | 实际主频 |
|---|---|---|
| 96 MHz | `0x0029250A` | PLL ×12 = 96 MHz |
| 72 MHz | `0x001D250A` | PLL ×9 = 72 MHz |
| 60 MHz | `0x0037250A` | HSE/2 ×15 = 60 MHz |

## 结果（16 KiB @0x20000000，SWCLK 60 MHz，halt，`--no-reset`）

| 目标主频 | 读 MB/s | 写 MB/s |
|---|---:|---:|
| **96 MHz** | **3.64** | **3.86** |
| 72 MHz | 3.56 | 3.86 |
| 60 MHz | 2.82 | 3.72 |

目标 96 MHz 下再扫 SWCLK：

| SWCLK | 读 | 写 |
|---|---:|---:|
| 50 MHz | 3.12 | 3.31 |
| 60 MHz | **3.64** | 3.86 |
| 64 MHz | 3.60 | **3.95** |

全部用例 `data_match=true`、`restore_match=true`。

## 结论

1. **目标 CPU 主频确实影响速度**：96 > 72 > 60，60 MHz 时读掉到 2.82
   （AHB-AP 响应慢，读路径对目标延迟更敏感）；写受影响小。
2. 之前"F103 最好成绩在 60 MHz"指的是 **SWCLK 60 MHz**，不是目标主频；
   目标主频应当尽量高（96 MHz）。
3. F103 最佳组合：**目标 96 MHz + SWCLK 60–64 MHz**，读 3.6、写 3.9–3.95，
   与历史最好（3.72–3.75 / 4.0）在同一水平（差异主要来自目标固件本身的总线负载）。
4. 测速必须用 `--no-reset`：`reset halt` 会把目标停在复位向量，此时固件还没
   跑 `clock_init()`，F103 待在 HSI 8 MHz，吞吐会掉到 1.5 MB/s 左右。

## 复现历史最好水平（20 KiB，60 轮，SWCLK 60 MHz）

历史记录（`releases/openocd_pipeline_20261025/`）：F103 HCLK=64 MHz、20 KiB、
60 轮、60 MHz SWCLK 下，nightly 读 3.18 / 写 4.11，补丁版读 **3.72** / 写 **3.95–4.03**。

用 `stm32f103_scope` 复测（同一协议 20 KiB × 60 轮）：

| 目标 HCLK | OpenOCD | 读 | 写 |
|---|---|---:|---:|
| 64 MHz | 补丁版 | 3.29–3.55 | 3.70–3.89 |
| **96 MHz** | **补丁版** | **3.77–3.80** | **3.98–4.00** |
| 96 MHz | nightly | 3.19 | 3.99 |
| 96 MHz，SWCLK 64 | 补丁版 | 3.77 | 3.88 |

结论：

1. **历史最好水平已复现**：补丁版 3.77–3.80 读 / 3.98–4.00 写，与历史
   3.72 / 3.95–4.03 一致（读还略高）；
2. **补丁的 +18% 读优势仍在**：nightly 3.19 vs 补丁 3.77；
3. 目标 HCLK 96 MHz 比 64 MHz 更好（3.77 vs 3.3–3.55），写基本持平；
4. SWCLK 60 的读最好（3.77），SWCLK 64 的写略低（3.88）。
