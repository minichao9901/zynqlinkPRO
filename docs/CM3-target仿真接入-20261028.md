# 真实Cortex-M3仿真

入口tools/run_cm3_sim.py使用Vivado2018.3/XSim。默认模型目录：
`reference/cortex_m3_on_xc7a100t/cm3_core/Arm_ipi_repository/CM3DbgAXI/rtl`。

这是已有的Xilinx加密Cortex-M3/DAP RTL。外接AXI/SRAM及可选旁路TAP为测试模型，不声称整颗F103外设或电气模型已被仿真。默认模型的34个RTL/include文件、上游LICENSE和README已纳入Git，普通clone即可取得；来源和SHA-256见cm3-model.json及required-dependencies.json。冗余Eval包和上游示例工程不作为仿真依赖。

```powershell
python tools/run_cm3_sim.py --top tb_cm3_jtag
python tools/run_cm3_sim.py --top tb_cm3_swd
python tools/run_cm3_sim.py --top tb_cm3_etm
python tools/run_cm3_matrix.py --out E:/zynqlinkPRO-work/cm3-matrix/results.json --case-logs
```

支持CM3_RTL、--rtl和--work-dir。Vivado默认安装路径为E:/Xilinx/Vivado/2018.3，其他机器可通过XILINX_VIVADO指定安装目录。默认快照位于项目外../zynqlinkPRO-work/cm3_sim，可用ZYNQLINK_WORK_DIR修改。完整矩阵含窗口外拒绝点，不应一律算通过。

tb_cm3_jtag覆盖真实串行DP/AP、AXI/引脚选择、scalar/batch/packet、HSS、错误围栏、不可变bank、非对齐RTT、1KiB分界及DDR-before-RdOff。本轮在精简依赖后重新建立快照验证，结果见精简验收摘要。
