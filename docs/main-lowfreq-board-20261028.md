# main 低频 SWD 检查点板测（2026-10-28）

**已按用户要求暂停，未合入 main；当前为实验检查点。** 状态、未归因问题及合并建议以[工作日志](main-lowfreq-progress.md)为准。
基线为 main `d42b601`，FPGA 为 xc7z020clg400-2，目标 F103 保持原 96 MHz 配置。
两版均按 FCLK 120 MHz 构建，固件限制 SWCLK≤60 MHz；没有采用早期旧工程的 150 MHz 结果。

150 MHz 两版均失败。检查点的最差路径仍在 HSS sampler 的 count→state 路径。
最终 bit 来自已布线检查点，仅修改 SWCLK 的 SLEW/DRIVE 后重新进行 STA、DRC 和 bitgen，逻辑及布线未重新修改；源 XDC 同步为 SLOW/4 mA。
SWDIO 保持 FAST/8 mA。IO 属性不属于当前 AXI 时序配置寄存器。

## 同环境吞吐（十进制 MB/s）

SRAM 为线性 20 KiB、3 会话×100 次/方向，全部字节与恢复检查通过。
标准 API 使用与上一轮 main 相同的 `--prefix-words 2`；OpenOCD 保持 target clock、不复位目标。

## 低频与因果对照

最终配对：250 kHz..60 MHz 共 28 个请求频率点，每点每方向 20 KiB 随机读写与恢复全部通过。
包含 35.5/36/37 MHz 的原失败区间及 46/47 MHz 实际 PLL 频率落入较低档的情况。
7 个低频/边界点另做每点每方向 80 KiB，全部通过。
RTT 1/10/25/35/40/45 MHz、HSS 15/25/35/40/45 MHz 的成功会话通过数据、序号/帧和恢复检查。
main 在 250 kHz..30 MHz 的已测低频点未通过连接；35/40/50/60 MHz SRAM 通过。

| 1 MHz 实验 | 接收模式 | 结果 |
|---|---|---|
| FAST/8 mA | 新边界 | ACK=101，失败；A/B/A 重复成立 |
| SLOW/4 mA | 旧边界 | ACK=100，错位 |
| SLOW/4 mA | 新边界 | ACK=001、DPIDR 正确、SRAM 通过 |

这是当前链路的数字采样/配置对照，不能代替示波器对模拟振铃或串扰的确认。
校准过程保留了一次 USB 掉线、HSS 少量跳点及分档失败数据，没有把失败样本计为通过。
最终完整 SRAM、核心寄存器、RCC 与测试前一致。详细可机器读取的结果见[汇总 JSON](measurements/20261028-main-lowfreq-board/summary.json)。
