## 使用流程

在烧录、调试、RTT Viewer或波形页选目标、载入目标MCU ELF后，其余页显示会话目标和“复用 文件名”。本页目标不匹配时，先点“沿用目标”，再点复用。所有动作只准备配置、解析符号，不连接、复位或烧录硬件。

会话目标是用户选择，不代表已识别的硬件；ARM调试/波形仅有架构选项时继承同架构会话目标，不从ELF架构推断具体板型。烧录页只接受自己已有算法的目标。

ELF以完整SHA-256标识，显示架构和12位哈希摘要；只保留当前一个ELF的内存副本，刷新需重新选择。内容副本避免消费者改写缓存；同名不同字节得到不同身份。摘要未完成及旧异步摘要均不能成为可复用文件。

显式沿用目标会退役本页旧固件/符号、RTT地址、波形变量和DWARF类型/数组、调试观察项和断点配置。新ELF复用时重新解析；不复制旧解析结果或地址。选择BIN/HEX会清空共享ELF，不宣称旧符号仍与该固件匹配。

原Flash/RTT/调试/波形的切页被动目标同步已撤下，目标变更改由显式入口执行。原有调试页已连接时的状态刷新仍保留。请求时钟保持各页原值，不把各业务档位强制相同。

任一探针连接、操作、采集、连接/清理在途或错误恢复状态都会阻止新入口替换配置；不会为了复用自动断开其它会话。此规则也覆盖HID已连接但未启动RTT转发、USB数据端点打开等状态。各页原始手动载入入口保持自身既有行为，本批新增保护针对跨页复用。

ETM历史记录保留自身ELF/源码身份，本批不将历史ELF自动推广为实时目标配置；RTT转发暂沿用自身ELF地址入口。文件缓存不持久化目录授权或声明板上已下载。
