# 尾部固定100MiB录制区

用户要求“DDR尾部100MB，时间到或写满停止”。本实现统一使用 **100 MiB = 104,857,600字节**，地址以exclusive end表示。

| 用途 | 起始地址 | 结束地址（不含） |
|---|---|---|
| 正常PS DDR分配、heap及非OCM数据 | `0x00100000` | `0x10000000` |
| 迁移后的可选DAP诊断区 | `0x39000000` | `0x39100000` |
| 固定ETM录制区 | `0x39C00000` | `0x40000000` |

原诊断区 `0x3F000000–0x3F100000` 与新的尾部录制区冲突，已同步迁移链接脚本和TLB属性；不能将新录制RTL与旧ELF混用。
录制区在链接脚本中单独定义，不生成巨大NOLOAD清零段；正常PS分配和诊断区有边界断言。USB描述符/暂存沿用原有OCM及低DDR分配，不使用录制保留区。
PS在任何PL DMA前将全部100个1MiB页映射为NORM_NONCACHE；读回验收另用物理MEM-AP0排除CPU缓存假象。

配置DDR地图为1GiB，四象限样本独立。新增端点采样比较 `0x39C00000/0x3FFFFFF0` 与低512MiB对应地址，均独立，四处各16字节全部恢复；这是地址别名检查，尚不代替候选100MiB全区模式写入/读回验收。

生产数据是RAW4接收器归一化后的FRM1 formatter字节流，完整帧16字节，末尾允许0～15字节；不是按200MHz参考计数器生成的物理采样数组。
100MiB对应6,553,600个完整formatter帧。生产构建使用编译期固定帧计数和最后一帧标志，不在每个64位写拍上做任意byte-limit减法/比较。
历史小容量仿真保留显式参数0以复测原契约；正式控制器默认100MiB，仿真另以8KiB缩小同一固定帧计数模式，覆盖完整录制、写满、部分尾帧、FIFO溢出、停止、AXI错误和B响应延迟。

到时或最后一帧都产生唯一TLAST，停止接收，排空已接受的写拍和AXI响应后才发布完成。写满是正常结束，stopReason=2；时间到为0，人工停止为1，故障为3。只有成功B响应才计入有效字节数。
容量结束的已存记录按完整帧结束；停机CDC/源FIFO排空时丢弃的尾部不能污染记录的tailBytes或tailAmbiguous。异常流仍有每burst硬上界，不能写到`0x40000000`及以后。

主机默认从已加载PL公布的固定区获取容量。页面/保存元数据区分“采集时间到”和“缓冲区已满（100 MiB）”，单独记录请求时间是否达到；有效采集时间来自独立参考域硬件ticks，不包含USB下载时间。
用户当前1～2秒约10～20MB是当前工作负载，不宣称任意高频未过滤线路都只产生该数据量。

本次仍只进行最后一轮150MHz候选综合/布线，不扩展到160MHz以上；所有新RTL、固件与实际验收bit/ELF配对最终须一起记录版本和哈希。此文为正在进行的实现说明，不代表新产物已验收。
