# v1.3.12 三页侧栏与 H743 RTT 实板验收

2026-11-15（上海时间）。本轮范围为三个侧栏的浏览器复核、当前 H743 的 RTT Viewer 与 RTT 转发。使用 J7 `12345678` 和同序列号的 CDC `COM33`。目标 ELF 为 `stm32h743_rtt_speed/fw.elf`，SHA-256 为 `d0079519c3644ceab8bf5514980ac5ed30ac38f335a45d8680174d908a99073e`。先独立读取 H743 的 CPU/设备 ID、运行状态、RCC 与 Flash 装载段，核对 ELF 和 CPU480/HCLK240。实际 SWD 由探针 PLL/分频寄存器取证为 49,999,999.5 Hz。

| 数据与结束状态 | Viewer 丢失和错位计数为 0，转发读错/RdOff 错为 0，导出含真实 `hello world!`，STOP 和资源释放复核通过 | 同项通过 |

第一版候选实际已经收到 3,080,192 B，控制块地址却被初始化等待期间的统计刷新覆盖为「查找中…」。修订后在 MEM-AP 接管成功时同步提交会话、地址和通道状态，固化为 ZL-259 的回归判据。首次跑错的 CLI worker 就绪等待及该候选失败快照均保留。源码工作台也用同板独立跑通两路。

三个侧栏在 Edge 的 1366 px 和 430 px 视口验证无横向溢出。RTT Viewer 只有 ELF 入口，不再出现旧说明、芯片、扫描和复位控件。RTT 转发接受 ELF 或确切地址，串口提示只显示数量，具体名称仍可从下拉框或提示读到。J-Scope 保留周期、通路、时长、时钟和采样按钮，连接详情和高级选项可以展开，采样速率提醒仍在首层。本轮 J-Scope 验收为布局和控件可达性。
