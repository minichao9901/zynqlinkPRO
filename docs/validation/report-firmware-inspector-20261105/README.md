# ETM 报告与烧录器固件查看器

2026-11-05，基线57a4b64，分支codex/report-firmware-inspector。问题ZL-150、ZL-151。仅主机/Web改动，不修改RTL/PS、目标Flash/QSPI或板卡状态。

## Review与修改

ETM“报告”原实现仍围绕旧LA波形，仅从sample_depth/sample_rate取实际时长，没有展示当前DDR采集、环形覆盖、触发后窗和原生离线Profile；把目标CPU/TRACECLK标成“SWD时钟回读”，缺少timing的旧记录可能抛异常。现在提供概况、采集、完整性、周期和Profile分类，分为记录身份/配置、采集窗口/传输、解码完整性、执行周期、处理性能Profile；实际字段缺失标为未记录，历史LA/相位/SPI对照仅在记录确实带有数据时保留。已结束但请求窗口不完整的采集继续显示失败，解码成功不覆盖采集失败。

Profile明确分离硬件窗口、USB下载、离线任务与建库子阶段；子阶段不重复相加，未实测首屏/E2E不补估算。飞行记录区分累计/保留、物理覆盖/帧对齐移除、触发来源和后窗；参考拍不是CPU周期，环容量不保证触发前时长，Fault轮询可漏短异常。记录快照不冒充当前板状态。

烧录器右侧保留日志，增加“固件字节”和“ELF解析”。导入后打开字节页；BIN按基地址，HEX/ELF按现有烧录解析器提供区段，并可切换原文件偏移。小空洞填FF行为沿用烧录器且明确提示；大空洞不分配或伪造字节，NOBITS不当文件数据。512B分页、地址定位/跨区段跳转、ASCII显示；仅查看，不执行烧录。

ELF页支持ELF32/64、大小端与扩展表编号，提供文件头、程序头、节表和符号表（对应readelf常用-h/-l/-S/-s）。保留64位地址精度，表格100项分页、名称/地址搜索；截断/越界显式报错，换BIN/HEX清除旧ELF视图。当前不展开DWARF、重定位或动态表，不称完整readelf替代。原烧录格式支持范围不扩大。
