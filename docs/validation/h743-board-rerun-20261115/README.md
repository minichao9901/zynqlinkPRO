JTAG 烧录对照只在原生 OpenOCD 接管前补现有 ARM SWJ 选择序列，实际读取 50 MHz TAP 与 DEV_ID 后释放 DAP，沿用同一 OpenOCD、网页和扇区范围。对照用了本轮局部测试驱动，标准命令仍为失败。ZL-236 保留 F103ZE 已通过的范围，并记录 H743 复用该序列的对照结果。JTAG J-Scope 的 89/529 ticks 原生长窗组速与历史同档实测的差值小于 0.001%。450 ticks 八路的首次超阈证据保留在 ZL-070。

标准调试入口在两条链路均用 `HAL_GetTick` 做默认断点。`stepInto` 退到指令级，`stepOver` 自该函数返回进入主循环，随后 `stepOut` 在不退出的 `main` 到达 400 条指令上限，标准入口仍报通过。补验从 `main.c:480` 的调用指令 `0x08000a20` 进入 `trace_hook_mark`（`0x08000b9c`），步过至下一源码行（`0x08000b9e`），调用栈与 ELF 一致，随后步出回 `0x08000a24` 并恢复原 SP `0x2001fff0`。SWD/JTAG 50 MHz 均通过独立检查和断点恢复。

原生配对基线对照使用 512 words、depth 32、64 blocks、三次中位数及各 10 秒交替读写，RTT 使用 AXI 8 KiB 环 / 1024 B 搬运 / 3×2 s。SWD/JTAG 两条链路均恢复原临时 SRAM 字节及对应核心状态，RTT 零读错，逐字序号和最终发布量完全一致。

## 结果和现场恢复

干净 `--review` 汇总 H743 为 **13 通过、1 失败、9 待验、0 阻塞**，`accepted=false`。通过数含预检、最终状态和两次 ETM 中较新的通过项。失败是未加 SWJ 预选的原版 JTAG 烧录。9 个待验是 **SWD 3 轮跨页压力、JTAG 3 轮跨页压力、JTAG 网页 RTT 转发及 J-Scope 单路/八路**。六轮压力中可执行的软件子动作已通过 13 项，实体数据线动作待台架人员确认独立供电后完成。其他板卡在此跨板汇总中无本轮报告，其待验数与 H743 单板统计分开。定向烧录对照、严格步进和匹配性能保留独立结果，不替换原版统一入口判定。
