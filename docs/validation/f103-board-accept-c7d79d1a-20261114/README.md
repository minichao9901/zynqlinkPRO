首轮统一跑的 J-Scope 单路在 48 ticks 触及页面缓冲容量。随后八路 163 ticks 的 STOP 返回忙，统一验收阻断后续。用同一 J7 独立排空 32 个尾帧、确认停止，回写并逐字节核对 32 字节夹具后继续。保留两次原始失败。正常烧录复位失败与中断回滚通过分别记录。

SWD 软件压力最终复测三轮各 3 项通过。第 1 轮为 RTT 转发切页、Viewer 空闲重连和 J-Scope 活动断开。第 2 轮为 RTT 转发活动断开、Viewer 切页和调试空闲重连。第 3 轮为调试活动断开、RTT 转发空闲重连和 J-Scope 切页。物理断线尝试有超时和非计划时点断开，另一次串口提前关闭后转发停机未确认，三个受控物理用例待验。通过 DAP 会话 epoch、独立排空、夹具快照回写及现场读回完成恢复。后续最终复测只执行三轮软件动作。

JTAG 也执行了三轮。每轮 Viewer 和调试在建链处失败，RTT 转发与 J-Scope 网页动作按 ARM/JTAG 能力边界待验。每轮输出结果，最后读回目标运行并确认探针引擎空闲。

验收期间修正本机服务响应解包、原生 DAP 模块选择、USB 描述符枚举句柄释放、OpenOCD 验证标记、J-Scope 安全采样容量与 JSP v1/32 位 tick 回绕解析，并调整压力取证以使用 RTT 有界二进制窗口、在 J-Scope 停止后导出。复位验证的尝试保留为失败证据。底层来源仍为 `c7d79d1a`，补跑报告记录工作区修正，无法用跨板正式 `--review` 接受为干净源码结果。

最终现场核对发现 FPB CTRL 从 `0x260` 变为 `0x261`，比较器和其余 FPB 字节相同。独立恢复 FPB 并清除测试留下的调试使能，读回 DHCSR `0x01010000`、应用心跳继续前进、RCC 与基线相同。烧录的独立启动检查已加入调试配置恢复包装，随成功启动一并待板验。最终 512 KiB Flash 双读一致，SHA-256 `48f226217497607c696a156addbb363925577499b00ee64f187bd5eea7a94499`。本轮擦写覆盖的 20 KiB 与本轮原备份相同。RTT/HSS 和物理采集/DMA 空闲、USB/HID 资源已释放。
