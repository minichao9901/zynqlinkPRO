# F103ZE 网页烧录复位与 USB 数据拔插收尾

2026-11-14 基于 `ddddf042` 的本机源码工作台 v1.3.8。只使用 zynqlinkPRO J7 `12345678` 和 XSCT 下载线 `210299008529`。物理 MEM-AP0 核对正式 `prebuilt/qspi-release/` 的 PL 特征及 85,716 字节 OCM 执行段。被烧录应用为板上已有的 `prebuilt/golden/f103ze-cdc48.elf`，F103ZE CPUID `0x411fc231`、DBGMCU ID `0x10036414`。探针配对未加载或改写。

## ZL-235 网页“烧录后复位运行”

仅在烧录工具确认 STM32F1 Flash、Cortex-M3、高密度 F103 ID 和 zynqlinkPRO USB 身份时采用 J7 NRST。烧录会话释放后，在同一网页所有权内用同一 J7 的 SWD MEM-AP0 读取并清除旧 DHCSR 复位标志，再拉低 NRST 45 ms、释放并读回。页面成功需观察到新的复位标志和内核指令执行，排除暂停和锁死。CDC48 启动时会关闭 JTAG 引脚，所以 JTAG 烧录后的验证通过 SWD 完成。验证失败时页面提示 Flash 已写入及具体复位错误。已覆盖目标要求连接 J7 的 NRST。

| 网页轮次 | 擦写/读回/复位 | 调用总时间 | 独立启动核对 |
|---|---|---:|---|
| SWD 60 MHz 档，内置 F103 | 20,168 B、10 扇区通过，DHCSR `0x03010001` | 4.42 s | 心跳从 2,626,151,945 回到 1,947,615 后继续增长 |
| JTAG 60 MHz 档，导入 F103 CFG | 20,168 B、10 扇区通过，DHCSR `0x03010001` | 9.48 s | 心跳从 2,715,034 回到 1,834,109 后继续增长 |

两轮都启用网页的真实烧录及复位选项，没有另发复位指令。烧录前后各独立双读整片 512 KiB，SHA-256 均为 `48f226217497607c696a156addbb363925577499b00ee64f187bd5eea7a94499`。表中频率是烧录请求档位，复位通路为 SWD 1 MHz。调试页软件复位和 WebUSB 直连烧录不属于本轮验证范围。

## ZL-237 物理断线

1. 调试暂停轮，实际 SWCLK 59,999,999 Hz。暂停并单步后检测到 J7 数据连接消失，随后短暂重新枚举。HID 握手未收到匹配响应，自动恢复失败。独立 SWD 恢复 FPB 和原运行状态，随后 HID 只读状态也恢复。HID 短暂失联的根因待定位。
2. 第 1 轮重试进入调试暂停后，用户要求停止。在 J7 仍在线时退出测试，独立核对 FPB、RCC 和运行状态。J-Scope 和 RTT Viewer 两轮未执行。

最终复核完整 Flash 与原备份一致，FPB 一致，应用心跳继续增长，RTT/HSS 和物理采集/DDR/DMA 空闲。本轮隔离浏览器及本机测试服务已退出。保留 `build/f103-web-reset-usb-20261114/` 内的原始结果、私有备份和独立收尾读回。物理验收保持待验。
