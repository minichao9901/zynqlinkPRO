# 交互火焰图HTML与bridge交付

本轮为ZL-012增加独立HTML导出，保留原始执行序号、完整调用深度与事件，不依赖超宽SVG画布。Web导出按钮、下载API、Trace CLI及bridge EXE离线接口共用同一生成器。SVG兼容导出仍保留，200000调用段边界未取消。

[使用说明](../../flame-html-export.md)。H743数据来自已有初始化/单次echo记录，本任务没有USB/HID/串口/JTAG访问，也没有改变板上状态。
