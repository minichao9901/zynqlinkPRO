## 示例来源及能力边界

复用已随程序分发的 `examples/h743-superlink-reference.etmrecord`，源码对应 `tools/tests/fixtures/h743-etmv4/h743.etmrecord`。来源为 superlinkPRO / Kingst LA 的 H743 历史参考采集，**不是当前板卡采集，也不是本轮 Zynq 上板证据**。

记录 717485 字节，SHA-256 `734611966188b8a0d1c611b545f0fcd080944a7d298f581d83027e43f8335706`。经现有导入校验器与原生解码链处理，得到 210497 条指令路径、14265 包、11 个异常。保留原来的未知执行和捕获边界；包错误为零不能证明完整执行流。

该示例保留 ELF、文件名、行号和机器码，15 个源码条目的正文均为空；教程明确说明此限制，不补入另一次编译的源码。ETM 也不提供变量值历史。自己的完整记录带有匹配源码快照时，源码窗格才显示正文。

前端按示例 SHA 与仍存在的记录 ID 缓存导入结果；再次打开复用已导入记录。缓存先于解码写入，解码失败可重试。示例接口只读取固定文件，不枚举 USB、不创建记录；实际导入走既有校验流程。
