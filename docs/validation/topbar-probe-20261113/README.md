# 顶栏探针连接验收

2026-11-13 源码候选。工作台顶栏集中提供「连接探针」和「断开连接」，下拉菜单可单独申请 USB 或 HID。浏览器首次使用分别申请两项权限，申请成功的一路可独立使用。已授予的浏览器权限在断开后仍可复用。

- 移除针对其他探针的 HID 0x3A 复位模式控件和命令。J7 的 GPIO2 在调试端口启用期间主动驱动高低电平，端口关闭时转为高阻。保留 OpenOCD Wasm 的全局 NRST 硬复位路径。本轮未触发目标复位或测量 NRST 波形。
- 顶栏在 RTT Viewer、调试器、内嵌 ETM、RTT 转发和硬件 J-Scope 页调用原有工具的连接流程。烧录器按业务命令认领探针，低频 J-Scope 在开始轮询时认领。独立 ETM 页保留独立入口。顶栏断开走现有释放和停止流程，串口仍由串口页管理。
- Chrome 通过本机服务枚举 J7 的 USB、HID，烧录器页面点击连接时没有打开两路句柄。在 RTT 转发页点击顶栏后，真实 HID 读取到 `0.7-nonce32`，断开后服务收到 HID close。模拟调试器连接和断开、内嵌 ETM 隐藏原按钮、390 px 顶栏可见性均通过。
- Chrome API 测试替身曾确认同一次点击能够发出两项请求。Chrome 156 真机首次使用只显示 USB 框，第二次点击才出现 HID 框。用户分别确认后，网页读到 HID 固件 `0.7-nonce32`，WebUSB 认领接口 0 后用 DAP_Info 读到 `2.1.1`。修正为首次逐项授权，第一步完成后顶栏将主按钮改为「连接 HID」。已经授权的通路可复用，本机工作台仍一次准备两路。

关联 ZL-102、ZL-207。本轮未烧录探针或目标。
