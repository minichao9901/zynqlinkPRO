# 变量监视编辑与 OpenOCD Wasm 正式运行时更新

2026-11-10（Asia/Shanghai）。监视表新增十进制 / 十六进制切换，偏好随页面保存。暂停目标后双击值或聚焦后按 Enter，输入新值并用 Enter 或“写入”提交，Esc 或“取消”放弃。支持已解析地址和类型的整数、浮点、指针、数组元素、结构体成员及不跨存储单元的 32 位以内位域。整数支持带 0x 前缀的位模式，浮点使用十进制输入。Hex 显示浮点的原始 IEEE 位模式。未知类型、只读类型及 ELF 只读段不开放编辑。

每次修改独占当前调试会话，在目标状态重新读回为暂停后写入，再逐字节回读。位域使用当前内存做读改写，保留相邻位。写入异常保持错误可见，不重放请求。后台刷新保留正在编辑的输入，目标、ELF 或监视项改变后拒绝旧编辑请求。

命令行增加 `p/x SystemCoreClock`，结构体 / 数组的成员和位域复用监视表的十六进制格式。`p` 默认行为保留，Tab 补全和帮助中新增 `p/x`。
