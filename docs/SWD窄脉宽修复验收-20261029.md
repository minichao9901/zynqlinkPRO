# SWD 窄脉宽修复验收（2026-10-29）

当前 F103CB 与接线已完成生产 SWD 路径的功能修复验收。新配对位于 `prebuilt/20261029_swd_short_high/probe.bit` + `probe.elf`，实际加载文件及 SHA-256、源码提交、构建选项、原始结果索引见同目录 `manifest.json`。既有已知可用配对继续保留。

## 上拉结论

SWDIO 保留已有 FPGA 内部上拉；SWCLK 不新增上拉。当前 XDC 已对 SWDIO 设置 `PULLUP true`，SWCLK 使用 SLOW/4 mA 推挽输出。

针对本次 STM32F103，ST 的 [AN2586 Rev 8，§5.3.3，第 20 页](https://www.st.com/resource/en/application_note/an2586-getting-started-with-stm32f10xxx-hardware-development-stmicroelectronics.pdf) 说明：SWDIO 内部上拉、SWCLK 内部下拉，已有内部偏置时无需额外外部电阻。此结论不代替其他目标芯片的数据手册要求。此次未改动板上电阻；不能把低频故障归因为“缺少上拉”。

## 实现与接收窗口

- `SWD_FEATURES[4]` 声明支持窄脉宽；旧 bitstream 保持原固件兼容路径。
- `SWD_CFG[19]` 选择单 FCLK 高电平，逻辑位周期保持 `FCLK / (2 × (delay_fast + 1))`。`delay_fast[7:4]` 使用 CFG[31:28]，低四位仍为 CFG[16:13]，覆盖 250 kHz。
- SWD 请求频率低于 35 MHz 时使用窄脉宽与较高 FCLK。实际位速率不超过请求；实际 SWCLK ≤25 MHz 使用早边界/Q2，超过 25 MHz 使用晚边界/Q1。其余频点与 JTAG 延续原有选档。
- 例如请求 250 kHz：实际 FCLK 119,999,998 Hz、半周期 240 拍、实际 SWCLK 249,999.996 Hz、请求高电平约 8.333 ns。请求 30 MHz：半周期 2 拍、实际 SWCLK 29,999,999.5 Hz。请求 35 MHz 切回普通模式，实际 SWCLK 34,615,384 Hz。
- 主机报告和 RTT/HSS 状态均计入扩展分频，不再将所有线速率报告为 FCLK/2。HSS 原有最低配置频率仍为 15 MHz，RTT 为 1 MHz；250 kHz 是 DAP 传输验收下限。

窄脉宽由原 FSM 的每个上升沿产生，增加一拍 FCLK 输出延迟，并覆盖 SWJ 激活序列。高电平宽度取决于实际 FCLK；记录中的纳秒数是 RTL 请求值，未测量 MCU 引脚模拟波形。

## 验收

1. FPGA routed FCLK 120 MHz：setup +0.119 ns、hold +0.042 ns，DRC/bitgen 通过。未提高 60 MHz 线速率上限。
2. 最终配对完成 43 个 SWD 请求频点（250 kHz～60 MHz，含 20/25/35 MHz 分档附近非整数点）。每点 4096-byte 随机 SRAM 写读 3 或 5 轮，DPIDR、全部数据与原 SRAM 恢复校验通过，RCC 前后一致。
3. 六档 JTAG 请求 250 kHz/1/10/30/50/60 MHz，通过 IDCODE、块写、连续及非对齐读和 SRAM 恢复。请求 50 MHz 经现有校准降至实际 TCK 44,999,999 Hz；60 MHz 请求实际 59,999,999 Hz。逐点实际 FCLK/TCK 在原始 JSON 中。
4. RTT 在请求 1/15/50 MHz 下各完成 21 轮，共 19,965 bytes，CDC 逐字节一致。HSS v1/v2 单变量及 v2 八变量在 15/50 MHz 通过，DAP 上下文、队列背压及 SRAM 恢复通过。服务实际时钟上报也经核对。背压测试主动暂停主机，会产生已计数的跳点，此处不声称零跳点性能。
5. 真实 CM3 仿真：最低 250 kHz 的 1/2/17 字块读写通过；晚接收窗口通过 1/2/127/256/770/1023 字块读写，以及 RTT/HSS。所有窄脉宽测试检查 pad 高电平宽度。

首次最低频仿真仅在部分子项 PASS 后触发固定轮询上限，旧 runner 仍返回成功。已把测试台等待预算按分频扩展，并使 runner 遇到 Fatal/Error/FAIL 必须失败；重新执行后全部完成通过。不能把旧摘要的 `passed=true` 当成完整通过。

早边界统一配置在 30 MHz 失败；晚边界/Q2 在约 26.47～28.125 MHz 仍失败。相应失败配对和结果单独标为 rejected，最终使用上述 Q1/边界组合。

## 同配对因果对照与边界

完整工程中，固定 FCLK 119,999,998 Hz、SWCLK 9,999,999.833 Hz、分频与接收窗口，仅切换 CFG[19]；SWJ 的分频也在该点相同。普通高电平约 50 ns 时返回 ACK5，窄高电平约 8.333 ns 时得到正确 DPIDR；连续结果为 FAIL → PASS → FAIL → PASS。

这证实了脉宽相关性及本板的功能规避有效，尚未确认模拟电气机制，也不证明所有目标均适用。没有示波器测量依据时，不把串扰、振铃或额外时钟边沿当作已证实根因。目标 Flash 未写入。最终板上保留此新配对，SWD 恢复到请求 50 MHz、实际 49,999,999.5 Hz。
